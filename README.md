# June's personal website

Hosted on: [yjunechoe.github.io](https://yjunechoe.github.io/)

Built with [Quarto](https://quarto.org) (originally with [{distill}](https://rstudio.github.io/distill/)). GitHub Pages serves the rendered site from `docs/`.

- Build: `quarto render` (needs Quarto 1.10+, R, and [uv](https://docs.astral.sh/uv/) for the build hooks)
- Write a post: see [WRITING.md](WRITING.md)
- Posts from the distill era: see [_distill/README.md](_distill/README.md)
- Publications and packages: edit `research.yml` and `software.yml`
