Packages

ggtrace

Maintainer, Author · R

Programmatically explore, debug, and manipulate ggplot internals. A low-level interface that extends base R's trace, plus workflow functions that make ggplot internals more accessible.

GitHub Website useR! 2022 talk rstudio::conf 2022 talk Paper

jlmerclusterperm

Maintainer, Author · R, Julia

Fast cluster-based permutation analysis for densely-sampled time data, with (generalized, mixed-effects) regression models. Uses MixedModels.jl and GLM.jl through JuliaConnectoR.

CRAN GitHub Website

pointblank

Author · R, HTML/CSS, JavaScript
